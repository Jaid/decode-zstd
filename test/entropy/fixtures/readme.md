# Entropy reference fixtures

## `predefined.json`

The literal-length, match-length and offset distributions and every corresponding decoding-table row are transcribed from the supplied `zstd_compression_format.md`, Appendix A. Tests compare symbols, bit counts and baselines independently of the header parser.

## `reference.json`

Generated by `scripts/entropy/generate-reference.c` linked against unmodified upstream Zstandard v1.5.7. It contains 12 Huffman cases with original bytes, serialized trees and both one-/four-stream compressed payloads, plus 12 FSE distributions with serialized normalized-count headers and every native decoding-table row.

The generator uses a fixed xorshift seed and multiple alphabet/distribution patterns, including sparse high symbols, all-byte alphabets and highly skewed frequencies. Every generated Huffman stream is decompressed again by the upstream C implementation and compared with the original bytes before emitting the fixture.

To regenerate, place the upstream release in `temp/zstd-1.5.7`, then run:

```sh
make -C temp/zstd-1.5.7/lib -j4 libzstd.a
cc -O2 -I temp/zstd-1.5.7/lib scripts/entropy/generate-reference.c temp/zstd-1.5.7/lib/libzstd.a -o temp/generate-reference
temp/generate-reference > test/entropy/fixtures/reference.json
bun test
```

For a larger, uncommitted differential corpus:

```sh
temp/generate-reference 512 > temp/reference-512.json
bun scripts/entropy/check-reference.ts temp/reference-512.json
```

All fixture files are self-contained. The C source is only a development generator; it is not linked, loaded or otherwise used by the published TypeScript library.
